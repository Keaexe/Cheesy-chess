# Cheesy chess 🧀♟️
This is a web-based chess game to play against your friends in local.

![JavaScript](https://img.shields.io/badge/language-JavaScript-F7DF1E.svg)

![Dark Mode](https://i.postimg.cc/15y8Gp5V/Screenshot-20260915-093838.webp)

## Features :
+ Beautiful interface
+ Dark mode
+ Mobile friendly
+ Automatic checkmate
+ Highlight last move

## Installation & Usage

Since this is a static web application, no build process is required:

1. **Download the [latest release](https://github.com/Keaexe/Cheesy-chess/releases/latest)**  
   
2. **Use in your browser**
   + By click-dragging
   + By double clicking

You can host this as well but I won't cover the installations steps
