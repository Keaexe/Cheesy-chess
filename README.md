## Features :
+ Beautiful interface
+ Dark mode
+ Mobile friendly
+ Highlight last move

## Installation & Usage

Since this is a static web application, no build process is required:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Keaexe/Cheesy-chess.git
   cd Cheesy-chess
   ```
2. **Use in your browser**
   + By click-dragging
   + By double clicking

You can host this as well but I won't cover the installations steps
